# Artisan Renovations Website

Archived source code for the Artisan Renovations website, a residential remodeling and renovation business owned and operated by Stephen and Jennifer Schertz.

---

## Project Overview

I designed, developed, secured, deployed, and maintained the company's public website, which served as the primary digital presence and customer lead-generation platform for the business.

This project demonstrates traditional full-stack web development, website administration, small business technology leadership, and customer-focused solution design prior to the widespread availability of AI-assisted development tools.

As co-owner and technology lead, I combined software development, web administration, business ownership, customer engagement, and marketing support responsibilities while helping to grow and operate a successful remodeling business.

## Security Notice

This codebase has not been updated, patched, tested, or reviewed against current security standards since 2019.

Because the repository reflects the architecture, frameworks, libraries, configuration settings, operating systems, hosting platforms, and development practices of its era, it may contain outdated dependencies, client-side scripts, server-side code patterns, or infrastructure assumptions that no longer align with modern security best practices.

This repository should be viewed as a historical portfolio artifact and should **not** be deployed to a production environment without:

- Secure code review
- Dependency analysis
- Framework updates
- Infrastructure modernization
- Configuration hardening
- Security testing
- Compliance validation

Any individual or organization choosing to reuse portions of this code should perform its own independent security review before deployment.
